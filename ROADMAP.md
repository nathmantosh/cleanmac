# CleanMac Feature Roadmap

This document outlines the planned feature roadmap and milestones for CleanMac. Feel free to join discussions or claim open issues!

---

## 📍 Milestones

### 🥚 Phase 1: Core Foundation (Completed)
* [x] SwiftUI Dark-Mode Dashboard with Glassmorphic design.
* [x] Asynchronous Junk File Scanner (caches, logs, developer folders, browser data).
* [x] Admin privilege escalation helper for system files.
* [x] Large File Finder (50MB+ filter).
* [x] Duplicate File Finder with cryptographic SHA256 checks.
* [x] Application Uninstaller and orphaned leftovers detector.
* [x] Standalone Menu Bar Extra app for quick stats.
* [x] Interactive Dashboard Shortcuts & cursor polish.

### 🐣 Phase 2: User Trust & Verification (In Progress)
* [x] Safe Category Selection & Checkbox states.
* [x] Detailed file-by-file inspection sheets with Finder shortcuts.
* [x] Accuracy verification reporting tool.
* [ ] **Localizations:** Add support for French, German, Spanish, Japanese, and Hindi.
* [ ] **Ignore Lists:** Let users exclude specific directories or file extensions from scans.

### 🐥 Phase 3: Automation & Integrations (Upcoming)
* [ ] **Auto-Updater:** Check GitHub Releases API and alert users when updates are available.
* [ ] **Scheduled Cleaning:** Run background scans daily, weekly, or monthly.
* [ ] **App Bundling:** Bundle the executable in a proper `.app` format and distribute via `.dmg`.
* [ ] **Menubar Purge Actions:** Add "Purge Inactive Memory" and "Flush DNS" directly from the Menu Bar app.

### 🦅 Phase 4: Premium Tooling & Diagnostics
* [ ] **Active Memory Pressure Graph:** Display real-time CPU/RAM usage graphs in the sidebar.
* [ ] **Startup Optimizer:** Manage macOS launch agents, daemons, and login items.
* [ ] **Secure Shredder:** Safely overwrite and delete sensitive files to prevent data recovery.
