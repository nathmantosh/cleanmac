# Security Policy

We take the security and privacy of CleanMac seriously. As a utility that interacts with files and directories on your system, maintaining trust and safety is our highest priority.

---

## Supported Versions

Only the latest release is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| v1.0.x  | Yes       |
| < v1.0  | No        |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability (such as a privilege escalation bug in the admin clean helper or directory traversal issue), please report it responsibly:

1. Send an email to **mantoshdebnath@gmail.com** (or your preferred contact email).
2. Describe the vulnerability, including reproduction steps or a Proof of Concept (PoC).
3. We will acknowledge your report within 48 hours and work on a fix as quickly as possible.
4. We request that you do not disclose the vulnerability publicly until we have released a patch.
